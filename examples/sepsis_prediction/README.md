# Sepsis Prediction Example

This example demonstrates how to use **imperfekt** to predict sepsis from pre-hospital vital sign time series. The core idea is that *missingness itself* — captured as imperfekt features — carries predictive signal beyond what imputed values can provide.

## Overview

The experiment compares seven feature strategies head-to-head using XGBoost classifiers:

| Strategy | Description |
|---|---|
| `Base` | Baseline statistics (mean, std, min, max, etc.) on raw vitals |
| `Miss` | Imperfekt missingness features only |
| `Base+Miss` | Baseline + imperfekt features on raw vitals |
| `Base-LOCF` | Baseline statistics on LOCF-imputed vitals |
| `Base+Miss-LOCF` | Baseline + imperfekt on LOCF-imputed vitals |
| `Base-SAITS` | Baseline statistics on SAITS-imputed vitals |
| `Base+Miss-SAITS` | Baseline + imperfekt on SAITS-imputed vitals |

Each strategy is evaluated across a grid of cohort configurations, so results are stratified by how early in the encounter prediction is attempted and how much data is required per encounter.

## How `run_prediction.py` Is Structured

The script is organized as a linear pipeline that runs inside a three-level nested loop over experiment configurations.

### 1. Configuration (top of file)

```python
first_minutes = [30, 20, 10]       # how far into the encounter to look
minimum_durations = [40, 30, 20, 10]  # minimum encounter length required
minimum_counts = [5, 8, 10]        # minimum number of vital measurements required
imputation_strategies = ["locf", "saits"]
```

The full cohort input parquet is loaded once at the top, before any loop iterations.

### 2. Cohort generation (`utils.generate_cohort`)

For each combination of `(first_minute, minimum_dur, minimum_count)`, the raw data is filtered to:
- Keep only the first `first_minute` minutes per encounter
- Require at least `minimum_dur` minutes of total observation
- Require at least `minimum_count` vital sign measurements

Experiments with fewer than 100 positive sepsis cases are skipped.

### 3. Output directory

Each experiment writes its results to a timestamped directory:

```
<nemsis_path>/results/imperfekt/<date>/experiment_<datetime>_<config>/
```

### 4. Missingness profiling (`utils.compute_encounter_missingness`)

A per-encounter missingness rate is computed across all vital sign columns. This is reported as a summary statistic and passed downstream so models can be evaluated separately on high- and low-missingness subsets.

### 5. Imputation (`imputation.impute`)

Missing values are imputed using each strategy in `imputation_strategies`. Both the imputed DataFrames and the elapsed imputation times are stored. LOCF sorts by encounter ID and time, then forward-fills within each group; any leading nulls are back-filled with the per-encounter mean. SAITS fits a self-attention imputation transformer (from `pypots`) whose architecture scales automatically with cohort size.

### 6. Feature generation

Four feature DataFrames are produced per experiment:

| Variable | Source data | Method |
|---|---|---|
| `imperfekt_features` | raw vitals | `generate_imperfekt_non_seq_features` |
| `baseline_features` | raw vitals | `generate_baseline_non_seq_features` |
| `locf_baseline_features` | LOCF-imputed | `generate_baseline_non_seq_features` |
| `saits_baseline_features` | SAITS-imputed | `generate_baseline_non_seq_features` |

Joined combinations (`union_features`, `locf_union_features`, `saits_union_features`) are then created for the strategies that combine baseline and imperfekt features.

**Imperfekt features** are generated by `imperfekt.features.core.FeatureGenerator`:
- Binary observation masks
- Circular (time-of-day) features
- Temporal gap features
- Row-level imperfection percentage

**Baseline features** are standard per-encounter aggregations: mean, std, min, max, median, first, last, range, CV, skewness, kurtosis, Q1, Q3, IQR, variance.

### 7. Model training and evaluation

Seven `XGBoostModel` instances are instantiated (one per feature strategy). Each uses probability calibration and a threshold tuned to `target_sensitivity=0.95`. All models are trained and evaluated via `evaluate_and_compare_models`, which performs a stratified train/test split and computes AUROC, AUPRC, F-beta, and Brier score — with bootstrap confidence intervals — on the full test set and on the high/low missingness subsets.

### 8. Results export

For each experiment the following files are written to `SAVE_RESULTS_PATH`:

| File | Content |
|---|---|
| `model_comparison_<timestamp>.csv` | All metrics across all feature strategies |
| `feature_importance_<timestamp>_<model>_<feature>.csv` | XGBoost feature importances |
| `<feature>_<model>_shap_*.png` | SHAP summary plots |
| `best_model_params_<timestamp>_<model>_<feature>.json` | Tuned hyperparameters |
| `imputation_times.json` | Wall-clock seconds per imputation strategy |
| `imputation_logs/` | SAITS training checkpoints |
| `imperfekt_feature_names.txt` | Names of generated imperfekt features |
| `baseline_feature_names.txt` | Names of generated baseline features |

The script finishes each iteration by printing the best-performing feature strategy (by lower CI of AUPRC) for that cohort configuration.

## Setup

### Prerequisites

Configure your data paths in [config.py](config.py):

```python
class PATHS:
    NEMSIS_BASE = Path("/mnt/dataset/nemsis")

class VARIABLES:
    NEMSIS_YEAR_STR = "2024"
```

The script expects a pre-built parquet file at:

```
<nemsis_path>/model_input/sepsis_prediction_input.parquet
```

with at minimum these columns: `id`, `clock`, `sepsis_outcome`, and the vital sign columns listed in `imperfekt.config.global_settings.VITALS.PARAMS`.

### Dependencies

Core dependencies beyond `imperfekt`:

```
polars
xgboost
scikit-learn
shap
pypots          # for SAITS imputation
```

XGBoost and pypots are imported conditionally — the script will fall back gracefully if they are not installed.

### Running

```bash
cd examples/sepsis_prediction
python run_prediction.py
```

Results are written to `<nemsis_path>/results/imperfekt/`.
